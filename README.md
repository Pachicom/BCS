# ChemBio Lab 9

ChemBio Lab 9 — бесплатный статический учебный материал по химии и биологии для 9 класса. Сайт не требует библиотек, сервера, аккаунтов или сборщика; его можно открыть офлайн в современном браузере или опубликовать через GitHub Pages.

Это независимый вспомогательный ресурс, не являющийся официальным учебником или ресурсом органов образования. Перед использованием в классе учитель должен сверить темы и задания с действующей программой и учебником школы.

Интерфейс и учебные тексты сейчас на русском языке. Для обучения на казахском языке потребуется профессиональная локализация и проверка предметным редактором.

## Запуск

1. Откройте `index.html` в современном браузере.
2. Все основные ресурсы подключаются относительными путями; внешний сервер и интернет для самого сайта не требуются.
3. Прогресс хранится в `localStorage` текущего браузера и устройства. Для переноса используйте экспорт и импорт JSON в разделе «Мой прогресс».

## Файлы проекта

- `index.html` — страницы и интерфейс.
- `style.css` — тёмная и светлая темы, адаптивная раскладка, схемы и модели.
- `script.js` — навигация, тесты, симуляции, поиск и сохранение прогресса.
- `data.js` — учебные материалы, 84 вопроса, словарь и конфигурация лабораторий.
- `admin/index.html`, `admin/admin.js`, `admin/admin.css` — локальный редактор дополнительных терминов, тем и вопросов; в опубликованную версию сайта он не входит.
- `TEACHER_GUIDE.md` — сценарий урока, ограничения и рекомендации для общих устройств.
- `.github/workflows/pages.yml` — автоматическая публикация сайта на GitHub Pages.
- `LICENSE`, `CONTENT_LICENSE.md` — отдельные лицензии программного кода и оригинального учебного содержания.

## Публикация на GitHub Pages

1. Создайте GitHub-репозиторий и добавьте в него исходные файлы сайта. Перед первым коммитом проверьте, что PDF-файлы учебников и сгенерированный ZIP не добавлены. Правила в `.gitignore` помогают их исключить.
2. Отправьте изменения в ветку `main` или `master`.
3. В настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** в качестве источника публикации.
4. Дождитесь успешного выполнения действия **Deploy ChemBio Lab 9 to GitHub Pages** на вкладке **Actions**. Адрес опубликованного сайта появится в задаче развертывания.

Workflow публикует только `index.html`, `style.css`, `script.js` и `data.js`. PDF учебников, ZIP, исходники редактора и прочие файлы не попадают в развернутый сайт. Пути внутри сайта относительные и подходят для GitHub Pages как проекта, так и пользовательского сайта.

## Локальный редактор содержимого

Для редактирования на своём устройстве откройте `admin/index.html`. Редактор позволяет добавлять, изменять и удалять дополнительные термины, темы и вопросы, а также импортировать и экспортировать JSON-копию. Материалы сохраняются в `localStorage` этого браузерного профиля; это не общая база данных и не синхронизация для школы.

Редактор не включён в GitHub Pages и не защищён учётными записями. Не публикуйте его как административный интерфейс и не вводите в него конфиденциальную информацию. Чтобы изменить содержимое публичного сайта, обновите исходный `data.js`, проверьте изменения и отправьте их в репозиторий.
