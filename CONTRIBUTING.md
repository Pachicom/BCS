# Contributing to ChemBio Lab 9

Contributions that improve scientific accuracy, accessibility, and classroom usability are welcome.

## Educational content

- Check factual changes against a reliable source and include the textbook title, chapter, and page (or a stable public reference) in the pull request description.
- Keep explanations in your own words. Do not submit textbook scans, copied passages, answer keys, student records, or personal information.
- Label content that goes beyond the cited grade-9 textbooks as additional material.
- Have a qualified teacher review substantive changes before presenting them as classroom-ready.
- Keep quiz choices and explanations consistent with the relevant topic.

## Software changes

- Keep the site framework-free and runnable as static files.
- Test the affected page and interaction in a modern browser.
- Do not add analytics, advertising, external scripts, or collection of student data without explicit review and a clear privacy notice.
- The GitHub Pages workflow intentionally publishes only `index.html`, `style.css`, `script.js`, and `data.js`. Do not add private or copyrighted files to that allowlist.
